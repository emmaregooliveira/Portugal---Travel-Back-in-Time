PORTUGAL THROUGH TIME — WEBSITE FILES

Files
- index.html   Main page structure and content sections
- styles.css   Full responsive styling and colour system
- script.js    Timeline data, people directory, filters, detail dialogs, and navigation

How to use
1. Keep the three files in the same folder.
2. Open index.html in a modern web browser.
3. For best results, use a local development server (for example, VS Code Live Server).

Customising content
- Historical periods, dates, highlights, and event tables are in the `periods` array near the top of script.js.
- People profiles are in the `people` array in script.js.
- Resource links are in the `resources` array in script.js.
- Fonts are loaded from Google Fonts and the sample photography is loaded from Unsplash, so an internet connection is required for those assets. The site structure and interactions work without them.

Notes
- The timeline uses approximate dates where period boundaries are debated.
- The people directory mixes historical actors with modern diaspora and cultural connections, reflecting the wireframe.
- Check dates, biographies, image rights, and all external links before public launch. For a production version, consider switching to locally hosted images and adding item-by-item citations to detailed history content.
